# QuantumAIMobile

QuantumAIMobile is a free iOS workspace for:

- monitoring watchlists and status panels
- rehearsing strategies in simulation flows
- reviewing queued local actions and operational health
- using local reference and verification utilities on device
- following training, runbook, and onboarding content inside the app

What the App Store build does not do:

- no in-app purchase flow
- no paid subscription requirement
- no fiat checkout
- no exchange or brokerage account creation inside the app
- no order is broadcast to a live exchange from the default App Store flow

Actions shown in the app are used for local simulation, strategy rehearsal, and outbox review. Reference and verification screens are used on device only.

## Main screens

- Dashboard: system health, market snapshot, recommendations, and local order queue
- Simulations: scenario versions and safe practice flows
- Wallet: reference display, local signing tests, verification, and network selection
- Bots: DCA, grid, and copy-trade rehearsal controls with local outbox tracking
- Settings: runtime mode, market configuration, training links, and free access status

## Availability

The App Store version is intended to be distributed as `Free` / `Free of Charge`.
